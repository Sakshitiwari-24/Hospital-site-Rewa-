## 🏛️ Page Sections

1. **Hero** — Full-screen cinematic background with animated stats and CTAs
2. **About** — Split layout with mission statement and animated counters
3. **Departments** — 21 specialty department cards with hover animations
4. **Doctors** — 6 expert doctor profiles with glassmorphism cards
5. **Services** — Icon-based grid of hospital services
6. **Why Choose Us** — 4 pillars of excellence
7. **Insurance & Schemes** — Ayushman Bharat, ECHS, SGHS, CGHS, Cashless TPA
8. **Gallery** — Masonry image grid of hospital facilities
9. **Testimonials** — Auto-cycling patient testimonial carousel
10. **Health Blog** — 3 featured health tip articles
11. **Appointment Booking** — Full-width booking form
12. **Footer** — 4-column footer with map, contact info, and social links

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Sakshitiwari-24/rewa-hospital.git
cd rewa-hospital

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be available at `http://localhost:5173`

### Production Build

```bash
npm run build
npm run preview
```
